### CRUD API

**To use API you need:**

1. clone this repo
2. run npm install command to install all dependencies
3. to the main directory file .env with the number of port where you want to start the project. You can use .env.example file as an example

**You can use following scripts in the app:**

1. npm run start:dev - to start app in the development mode
2. npm run start:prod - to start app in the production mode
3. npm run lint - to lint files
4. npm run test - to run tests for files
